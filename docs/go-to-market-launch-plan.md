# Go-to-Market Launch Plan

Aufbauend auf `go-to-market-foundation.md`. Fokus: vom fertigen Produktkern +
öffentlichem Auftritt (Block 1–5) zu Pilot und Marktstart.

## ICP (Kurzform)

Freie/unabhängige Garage oder kleine Gruppe, DACH (Start Schweiz), 3–20
Mitarbeitende, nennenswerter Anteil an Zusatzarbeiten, digital-offen,
„no-nonsense“. Entscheider: Inhaber:in / Serviceleitung.

## GTM-Hypothesen

1. Der stärkste Hebel ist **belegbarer Zusatzumsatz** — Piloten überzeugen mit
   harten Zahlen (Freigabequote, Zeit bis Entscheid).
2. **Demo-first** schlägt Self-Service-Trial in dieser Zielgruppe (Beratung,
   Vertrauen, Onboarding).
3. **Referenzen aus der Region** treiben Empfehlungen (Verbände, Gruppen).
4. Der loginlose Kundenflow ist der „Aha“-Moment in der Demo.

## Phasen

### Phase 0 — Readiness (jetzt)
- Öffentlicher Auftritt live (Marketing-Site) ✅
- Legal-Entwürfe vorhanden (Review offen) ✅
- Produktkern funktionsfähig (Block 1–4) ✅
- Offen vor echtem Verkauf: Infrastruktur/Deployment (Block 6), Zahlungsanbieter,
  Legal-Finalisierung.

### Phase 1 — Soft Launch / Pilot (3–5 Garagen)
- Persönliches Onboarding, Branding + Vorlagen einrichten.
- Erfolg messen: Freigabequote, Median Zeit-bis-Entscheid, Zusatzumsatz.
- Wöchentliches Feedback → Produkt-/Preis-Feinschliff.
- Deliverable: 2–3 belastbare Fallbeispiele (mit Einwilligung).

### Phase 2 — Markteintritt Schweiz
- Direktvertrieb + Empfehlungen; Website als Conversion-Motor.
- Preise finalisieren, Zahlung live (Provider-Entscheidung).
- Content/SEO-Aufbau (Ressourcen/Blog), erste Case Studies.

### Phase 3 — DACH-Ausbau
- Gruppen/Ketten, Partner-/White-Label, API-Integrationen.

## Kanäle

Direktvertrieb · Pilot-Referenzen/Empfehlungen · Verbände/Gruppen · später
Content/SEO. Kein Performance-Marketing im Pilot.

## Erfolgskriterien (Launch)

- ≥ 3 aktive Pilotgaragen mit belastbaren Zahlen.
- Freigabequote > 55 %, Median Zeit-bis-Entscheid < 2 h.
- Mind. 2 verwendbare Fallbeispiele.

## Abhängigkeiten / Reihenfolge

Legal-Review → Infra/Deployment (Block 6) → Zahlungsanbieter → kostenpflichtiger
Marktstart. Pilot kann davor mit manueller Abrechnung starten.
